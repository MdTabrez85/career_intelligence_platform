\# AI-Powered Career Intelligence Platform



An AI-powered full-stack career intelligence platform developed as an MCA major project.



\## Technology Stack



\### Frontend

\- React

\- TypeScript

\- Vite

\- Tailwind CSS



\### Backend

\- Java 21

\- Spring Boot

\- Spring Security

\- Spring Data JPA

\- Hibernate

\- JWT

\- WebSocket



\### AI Service

\- Python 3.12

\- FastAPI

\- Pandas

\- NumPy

\- Scikit-learn

\- LLM

\- RAG

\- Embeddings



\### Database

\- PostgreSQL

\- pgvector



\### Infrastructure

\- Docker

\- Docker Compose

\- Redis



\## Main Features



\- User authentication and role-based access

\- AI resume analysis

\- Job description intelligence

\- AI job matching

\- Skill gap analysis

\- Personalized career recommendations

\- RAG-based career advisor

\- AI mock interviewer

\- Real-time notifications

\- Career analytics dashboard
